# 🎴 Fortunes

A mystical tarot-based idle game where fortune meets strategy. Draw cards, build decks, and unlock the secrets of the arcana in this enchanting Godot-powered experience.

## 🎮 About

Fortunes is an idle fortune game that combines tarot card mechanics with strategic deck building. Players draw cards, manage resources, and progress through mystical challenges using the power of the major and minor arcana.

### Key Features

- 🃏 **78-Card Tarot System**: Complete deck including all major arcana and minor arcana suits
- ⚗️ **Strategic Deck Building**: Customize your deck to optimize fortune generation
- 💎 **Resource Management**: Earn and spend clairvoyance currency wisely
- 🎯 **Upgrade Systems**: Enhance your cards and abilities
- 🏆 **Prestige Mechanics**: Reset for powerful bonuses
- 🔮 **Mystical Theme**: Immersive tarot-inspired artwork and lore

## 🛠️ Technical Details

- **Engine**: Godot 4.x
- **Language**: GDScript
- **Audio**: FMOD integration
- **Platform**: PC (Windows/Linux/Mac)

## 🚀 Getting Started

### Prerequisites

- Godot 4.x Engine
- FMOD for Godot plugin (included)

### Installation

1. Clone this repository
2. Open the project in Godot 4.x
3. The FMOD plugin is pre-configured - no additional setup needed
4. Press F5 to run the game

### First Run

1. Start with tutorial mode to learn the basics
2. Draw your first cards and observe the fortune generation
3. Experiment with deck customization
4. Begin your journey through the tarot mysteries!

## 🏗️ Project Structure

- `Assets/Scripts/Core/` - Core utilities and foundation systems
- `Assets/Scripts/Managers/` - Game logic and state managers
- `Assets/Scripts/Systems/` - Global singletons and coordinators
- `Assets/Scripts/Data/` - Game data and statistics
- `Assets/Scripts/GUI/` - User interface components
- `Assets/Scripts/Models/` - Data structures and type definitions
- `Assets/Scripts/Utils/` - Utility functions and helpers
- `Assets/Scripts/CardDescriptions/` - Card-specific content
- `Assets/Scenes/` - Game scenes and UI layouts
- `Calculators/` - Card value and suit-specific logic
